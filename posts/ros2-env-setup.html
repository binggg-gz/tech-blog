Ubuntu 24.04 + ROS 2 机器人开发环境搭建笔记

从零开始记录 ROS 2 Jazzy 的安装、工作空间结构和 colcon 构建流程,以及搭建轮式机器人自主移动项目的完整环境配置。

计划做一个轮式机器人的自主移动与避障项目,技术栈定为 Ubuntu 24.04 + ROS 2 Jazzy + Gazebo + Nav2 + slam_toolbox。这篇笔记记录环境搭建的完整过程,方便换机器时复现,也给同样在入坑的人一个参考。

为什么选 ROS 2 Jazzy

Ubuntu 24.04 LTS 对应的 ROS 2 版本正是 Jazzy Jalisco,它属于长期支持(LTS)版本,会维护到 2029 年。对于要长期维护的项目,LTS 是最稳妥的选择。Jazzy 相比上一个 LTS(Humble)的主要变化:

  • 默认中间件切换为 rmw_fastrtps_cpp 的新版本,DDS 发现机制更快
  • Python 3.12 支持,彻底告别 3.8 时代的兼容性问题
  • launch 系统持续增强,参数声明更接近 YAML 原生

安装步骤

先设置 UTF-8 locale 和 ROS 2 的 apt 源:

sudo apt update && sudo apt install locales software-properties-common -y
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

sudo add-apt-repository universe
sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

桌面完整版(含 RViz、Gazebo、 demos)适合开发机:

sudo apt update
sudo apt install ros-jazzy-desktop -y
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc

如果是无显示环境的机器人主板,装 ros-jazzy-ros-base 就够了,能省下几个 GB。

工作空间结构

ROS 2 开发推荐用工作空间(workspace)组织代码,一个典型的机器人项目布局:

robot_ws/
├── src/
│   ├── robot_description/     # URDF / xacro 机器人模型
│   ├── robot_bringup/         # launch 文件、参数配置
│   ├── robot_navigation/      # Nav2 参数与行为树
│   ├── robot_slam/            # slam_toolbox 配置
│   └── robot_perception/      # 传感器驱动
└── install/                   # colcon build 产物

创建并编译:

mkdir -p ~/robot_ws/src && cd ~/robot_ws
colcon build --symlink-install
source install/setup.bash

--symlink-install 很关键:它用软链接代替拷贝,改 Python 代码后不用重新编译,直接 source install/setup.bash 即可生效。

核心组件与用途

组件作用备注
Gazebo物理仿真环境Jazzy 对应 Gazebo Harmonic
Nav2自主导航框架路径规划 + 行为树恢复
slam_toolbox同步定位与建图激光雷达方案首选
RViz2可视化调试看话题、发坐标、调试必备

环境验证

安装完成后跑一遍官方 demo,确认节点通信和 topic 机制正常:

ros2 run demo_nodes_cpp talker
# 另开终端
ros2 run demo_nodes_py listener

能收到 Hello World: 1、2、3… 就说明基础链路通了。
